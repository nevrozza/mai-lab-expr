# Отчёт по лабораторной работе №3

## Тема

Преобразование арифметических выражений с использованием дерева выражения.

## Задание

Вариант 6: упростить выражение, выполнив приведение подобных членов.

Необходимо разработать программу, которая считывает арифметическое выражение, строит его внутреннее представление и выполняет преобразование выражения согласно варианту задания.

## Цель работы

Целью работы является изучение способов представления арифметических выражений в виде дерева, а также реализация алгоритмов анализа, преобразования и вывода выражений.

В ходе выполнения лабораторной работы требуется:

- разобрать входную строку на токены;
- преобразовать инфиксную запись выражения во внутреннее представление;
- построить дерево выражения;
- выполнить упрощение выражения;
- вывести результат в корректной форме.

## Используемые структуры данных

В программе используются следующие основные структуры данных:

- стек операторов;
- очередь токенов;
- дерево арифметического выражения;
- узлы дерева, содержащие операторы, числа или переменные.

Дерево выражения удобно тем, что каждый внутренний узел соответствует операции, а листья соответствуют операндам. Такое представление позволяет обходить выражение рекурсивно и выполнять локальные преобразования над поддеревьями.

## Описание алгоритма

Работа программы состоит из нескольких этапов.

### 1. Лексический анализ

На первом этапе входная строка разбивается на отдельные токены. Токенами являются числа, переменные, арифметические операции и скобки.

Во время чтения выражения проверяется корректность последовательности токенов и баланс скобок. Это позволяет обнаружить ошибки до построения дерева выражения.

### 2. Преобразование выражения

После разбиения на токены выражение переводится из инфиксной формы в постфиксную. Для этого используется стек операторов. Приоритет операций учитывается при переносе операторов в выходную очередь.

Такой подход упрощает последующее построение дерева выражения, поскольку постфиксная запись однозначно задаёт порядок применения операций.

### 3. Построение дерева выражения

По постфиксной записи строится дерево выражения. Если встречается операнд, создаётся лист дерева. Если встречается оператор, из стека извлекаются необходимые операнды, после чего создаётся новый узел операции.

Полученное дерево отражает структуру исходного выражения и порядок вычислений.

### 4. Приведение подобных членов

Основная часть лабораторной работы связана с упрощением выражения. Для этого дерево обходится рекурсивно. Подобные слагаемые объединяются, если они имеют одинаковую буквенную часть.

Например, выражение вида:

```text
2*x + 3*x
```

может быть преобразовано к виду:

```text
5*x
```

А выражение:

```text
x + x + y
```

преобразуется к:

```text
2*x + y
```

При упрощении учитываются коэффициенты перед переменными и знаки операций.

## Особенности реализации

Программа разделена на логические части:

- чтение и проверка входного выражения;
- работа с токенами;
- реализация стека и очереди;
- построение дерева выражения;
- преобразование дерева;
- вывод результата.

Такое разделение делает программу более понятной и упрощает отладку.

## Пример работы

Входное выражение:

```text
2*x + 3*x + y
```

Результат преобразования:

```text
5*x + y
```

Другой пример:

```text
a + a + b + 4*b
```

Результат:

```text
2*a + 5*b
```

## Тестирование

Для проверки корректности работы программы использовались выражения:

- с одним слагаемым;
- с несколькими подобными членами;
- со скобками;
- с разными переменными;
- с числовыми коэффициентами;
- с некорректным вводом.

Особое внимание уделялось проверке баланса скобок и корректности порядка операций.

## Вывод

В ходе выполнения лабораторной работы была реализована программа для преобразования арифметических выражений. Было изучено представление выражений в виде дерева, реализованы структуры данных для разбора выражения и выполнено упрощение выражения путём приведения подобных членов.

Использование дерева выражения позволило удобно выполнять рекурсивную обработку и локальные преобразования подвыражений.
