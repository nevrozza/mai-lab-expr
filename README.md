# Отчёт по лабораторной работе №3 по курсу «Фундаментальная информатика»

**Тема:** Деревья. Преобразование арифметических выражений.

**Цель:** Освоить представление арифметических выражений с помощью дерева, а также реализовать преобразование выражения по заданному правилу.

**Задание:** Упростить арифметическое выражение, выполнив приведение подобных членов.

> **Вариант 6:** Упростить выражение, выполнив приведение подобных членов.

## Идея и метод решения

Основная идея заключается в том, что арифметическое выражение сначала переводится во внутренний вид, удобный для обработки.

Строковое представление плохо подходит для таких преобразований: приходится вручную учитывать приоритеты операций, скобки и порядок вычислений. Поэтому выражение разбирается на токены, после чего строится дерево выражения.

В дереве:
- листья — это числа или переменные
- внутренние вершины — арифметические операции
- поддеревья соответствуют подвыражениям

После построения дерева можно рекурсивно обходить выражение и собирать коэффициенты у одинаковых переменных.

Например:
```text
2*x + 3*x + y
```

После приведения подобных членов:
```text
5*x + y
```

> [!IMPORTANT]
> Подобными считаются члены с одинаковой буквенной частью. То есть `2*x` и `3*x` можно сложить, а `x` и `y` — нет.

## Структура программы

Программа декомпозирована на несколько логических частей:

- `main.c` — точка входа, чтение выражения и запуск решения
- модуль токенов — разбор входной строки на числа, переменные, операции и скобки
- стек операторов — используется при переводе выражения в постфиксную запись
- очередь токенов — хранит постфиксное представление выражения
- дерево выражения — основная структура для дальнейшего преобразования
- функции упрощения — поиск и приведение подобных членов

Такое разделение позволяет не смешивать парсинг, хранение выражения и само преобразование.

## Алгоритм

### Разбор выражения

1. Вводится арифметическое выражение
2. Строка разбивается на токены
3. Проверяется корректность скобок и порядка токенов
4. Инфиксная запись переводится в постфиксную с учётом приоритетов операций

### Построение дерева

1. Постфиксная запись просматривается слева направо
2. Если встречается операнд — создаётся лист дерева
3. Если встречается оператор — из стека достаются операнды и создаётся новая вершина
4. В результате получается корень дерева выражения

### Приведение подобных членов

1. Дерево обходится рекурсивно
2. Слагаемые разбираются на коэффициент и буквенную часть
3. Для одинаковых буквенных частей коэффициенты складываются
4. Нулевые коэффициенты убираются
5. Из полученного набора членов формируется упрощённое выражение

> [!NOTE]
> Такой подход удобнее, чем работа со строкой, потому что структура выражения уже восстановлена деревом.

2. Реализация разбора входного выражения на токены
3. Перевод инфиксной записи в постфиксную
4. Построение дерева выражения
5. Реализация преобразования для варианта 6

| **Ввод** | **Результат** |
|:--------|:-------------|
| `2*x + 3*x` | `5*x` |
| `x + x + y` | `2*x + y` |
| `a + a + b + 4*b` | `2*a + 5*b` |
| `3*x + 2*y + 7*x` | `10*x + 2*y` |
