# Отчёт по лабораторной работе №3 по курсу "Фундаментальная информатика"

**Тема:** Деревья. Преобразование арифметических выражений.

**Цель:** Освоить представление арифметических выражений в виде дерева и реализовать преобразование выражения по варианту.

**Задание:** Упростить арифметическое выражение, выполнив приведение подобных членов.

> **Вариант 6:** Упростить выражение, выполнив приведение подобных членов.

## Идея и метод решения

Работа ведется не с исходной строкой, а с деревом выражения, так как это требуется в условии лабораторной работы.

Сначала выражение разбирается на токены: числа, переменные, операции и скобки. Затем с учетом приоритетов операций строится промежуточное представление, по которому создается дерево.

В дереве:
- листья - это числа или переменные
- внутренние вершины - арифметические операции
- поддеревья - отдельные части исходного выражения

Для варианта 6 нужно найти слагаемые с одинаковой буквенной частью и сложить их коэффициенты.

Например:
```text
2*x + 3*x + y
```

После приведения подобных членов:
```text
5*x + y
```

> [!IMPORTANT]
> Подобными считаются только члены с одинаковой буквенной частью. `2*x` и `3*x` можно объединить, а `x` и `y` - нельзя.

## Структура программы

Логически программа разделена на несколько частей:

- `main.c` - точка входа, чтение выражения и запуск решения
- токены - разбор входной строки на числа, переменные, операции и скобки
- стек операторов - учет приоритетов операций при разборе выражения
- очередь токенов - хранение выражения после преобразования порядка операций
- дерево выражения - основная структура для дальнейшей обработки
- упрощение - поиск похожих слагаемых и пересборка результата

Такое разделение важно, потому что в этой задаче легко смешать парсинг, построение дерева и само преобразование. Тогда код быстро становится сложно отлаживать.

## Алгоритм

### Разбор выражения

1. Считывается арифметическое выражение
2. Строка разбивается на токены
3. Проверяется корректность скобок
4. Учитывается приоритет операций
5. Формируется представление, удобное для построения дерева

### Построение дерева

1. Операнды становятся листьями дерева
2. Операторы становятся внутренними вершинами
3. Для каждого оператора связываются левое и правое подвыражение
4. В конце остается корень всего выражения

### Приведение подобных членов

1. Дерево обходится рекурсивно
2. Для каждого слагаемого выделяется коэффициент и буквенная часть
3. Слагаемые с одинаковой буквенной частью группируются
4. Коэффициенты внутри каждой группы складываются
5. Члены с нулевым коэффициентом удаляются из результата
6. Итоговое выражение печатается обратно в читаемом виде

## Тонкости реализации

Основные сложности работы связаны не с самой формулой `2*x + 3*x = 5*x`, а с обработкой всех случаев вокруг нее.

> [!IMPORTANT]
> При разборе выражения нужно не потерять знак слагаемого. Особенно это заметно на вычитании: `x - 2*x` должно превратиться в `-x`, а не в `3*x` или `x`.

В реализации важно учитывать:

- приоритеты `+`, `-`, `*`, `/`
- скобки, которые меняют порядок вычислений
- разницу между числом, переменной и составным слагаемым
- случаи вида `x`, где коэффициент фактически равен `1`
- случаи вида `-x`, где коэффициент равен `-1`
- удаление членов с нулевым коэффициентом
- аккуратный вывод результата без `+ -`, лишних `1*` и пустых частей выражения
- освобождение памяти после работы с деревом и вспомогательными структурами

> [!NOTE]
> Отдельная неприятность - форматирование ответа. Даже если внутренне выражение упрощено правильно, плохой вывод может сделать результат нечитабельным.

3. Построение дерева выражения
4. Реализация обхода дерева
5. Реализация приведения подобных членов
6. Тестирование на обычных и пограничных случаях

Примеры:

| **Ввод** | **Результат** | **Что проверяется** |
|:--------|:-------------|:--------------------|
| `2*x + 3*x` | `5*x` | простое сложение коэффициентов |
| `x + x + y` | `2*x + y` | неявный коэффициент `1` |
| `a + a + b + 4*b` | `2*a + 5*b` | несколько групп подобных |
| `3*x + 2*y + 7*x` | `10*x + 2*y` | сохранение разных переменных |
| `x - x + y` | `y` | удаление нулевого коэффициента |
| `x - 2*x` | `-x` | корректная обработка знака |
